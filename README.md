# AI-Based Stock Price Prediction Using Machine Learning

An intelligent stock market prediction system that uses Machine Learning algorithms to analyze historical stock data and forecast future stock prices.

## Features

* Predicts future stock prices using Machine Learning models
* Analyzes historical stock market data
* Data preprocessing and feature engineering
* Visualizes stock trends and prediction results
* Performance evaluation using accuracy metrics
* User-friendly interface for stock analysis

## Requirements

* Python 3.x
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* TensorFlow/Keras (for LSTM model)
* yfinance (for stock data collection)

## Installation

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

## How to Run

Run the project using:

```bash
python main.py
```

## Project Workflow

1. Collect historical stock market data
2. Clean and preprocess the dataset
3. Train the Machine Learning model
4. Generate stock price predictions
5. Compare predicted and actual prices
6. Visualize results and evaluate performance

## Machine Learning Techniques

* Linear Regression
* Random Forest Regression
* LSTM (Long Short-Term Memory)
* Time Series Analysis

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Square Error (RMSE)
* R² Score

## Applications

* Investment decision support
* Stock market trend analysis
* Financial forecasting
* Educational and research purposes
